# To-Do List App

A simple Python mini project to manage daily tasks.

## Description
This project is a To-Do List application that helps users keep track of tasks. Users can add tasks, view all tasks, mark tasks as completed, and delete tasks they no longer need.

## Features
- Add a new task
- View all tasks
- Mark task as completed
- Delete a task
- Simple command-line interface

## Technologies Used
- Python 3

## How to Run
1. Open the terminal
2. Navigate to the project folder
3. Run the following command:

```bash
python todo_list.py
